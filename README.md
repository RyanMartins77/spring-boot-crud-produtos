# Spring Boot - CRUD de Produtos

Projeto desenvolvido para praticar e aprofundar meus conhecimentos em **Java e Spring Boot**, implementando uma API REST para gerenciamento de produtos.

### Tecnologias e conceitos utilizados:
- **Spring Boot:** desenvolvimento da API REST.
- **DTO (Data Transfer Object):** separação dos dados de entrada e saída da API.
- **Global Exception Handler:** tratamento global de exceções.
- **Spring Data JPA:** persistência e gerenciamento dos dados.
- **MySQL:** banco de dados relacional.
- **Arquitetura em camadas:**
  - Model: representação das entidades.
  - Repository: comunicação com o banco de dados.
  - Service: implementação das regras de negócio.
  - Controller: recebimento e tratamento das requisições HTTP.

O projeto conta com operações CRUD (Create, Read, Update e Delete), aplicando boas práticas de organização e separação de responsabilidades no desenvolvimento backend.
